# SıraCepte – Android indirme

Bu repo yalnızca SıraCepte Android uygulamasının kurulum dosyalarını (APK) barındırır. Uygulamanın kaynak kodu burada değildir.

- Uygulama hakkında: https://siracepte.web.app
- En son sürümü indirin: https://github.com/kadiryar571-eng/siracepte-indir/releases/latest/download/SiraCepte.apk

Uygulama Google Play'de yayınlandığında indirme oradan yapılacaktır.
